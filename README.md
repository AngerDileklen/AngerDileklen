## Featured project

### 🖋️ [Ink Notes](https://github.com/AngerDileklen/ink-notes)
Handwritten notes, PDF study and an ebook reader built for e-ink Android tablets. Pressure pen, shape snapping, 20+ paper types, audio that links to your strokes, an offline dictionary, and optional AI with your own key. No account, no tracking.
